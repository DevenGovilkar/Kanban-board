 📋 Kanban Board

A modern and responsive *Kanban Board* built using *HTML, CSS, and JavaScript*. It helps users organize tasks by moving them through different stages of a project using a clean drag-and-drop interface.

---

## 🚀 Features

- ✅ Create new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- 📌 Drag and drop tasks between columns
- 💾 Data stored using Local Storage
- 🏷️ Task priority (Low, Medium, High)
- 📂 Task tags
- 📱 Fully responsive design
- 🔔 Toast notifications
- 🎨 Modern dark-themed UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API
- Font Awesome
